# Mask dataset folder

Put the downloaded Kaggle dataset here, so that these two folders exist:

    datasets/ppe_mask/raw/kaggle_face_mask/images/      (853 images)
    datasets/ppe_mask/raw/kaggle_face_mask/annotations/ (853 PASCAL VOC .xml files)

Your own webcam sessions go in `datasets/ppe_mask/webcam/<session_name>/{images,labels}` (created by collect_webcam_faces.py).
`datasets/ppe_mask/prepared/` is generated by prepare_mask_dataset.py. Do not commit datasets to Git.
