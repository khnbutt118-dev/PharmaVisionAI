# Notebooks
Create/run notebooks here in this order:
1. `01_dataset_audit.ipynb` — image counts, dimensions, readability, class balance and source distribution.
2. `02_tablet_eda.ipynb` — visual sampling, label review, duplicates and acquisition-condition analysis.
3. `03_baseline_experiments.ipynb` — only after labels and leakage-safe splits are approved.

Notebook files are not pre-populated with fabricated dataset results. Use the scripts in `src/data/` to create the initial inventory.
